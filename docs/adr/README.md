# Architecture Decision Records

This directory captures significant technical decisions for the project. Each ADR records **why** a choice was made, not how it is implemented today.

To add a new ADR:

1. Copy `000-template.md` to a new file with the next number in sequence (for example `005-my-decision.md`).
2. Fill in the sections and set the status.
3. Update the status of any ADRs this one supersedes.
