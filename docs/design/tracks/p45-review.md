## Decisions

- **Unmeasurable chat audio fails closed.** P4.1 let a file whose container did not say how long it plays through; with forged headers that made the 5-minute rule optional. The two formats Copilot accepts are now measured the way decoders play them, so only a damaged or exotic file (ADPCM WAV, an MP3 without Layer III frames) is refused, and only in a chat. The web recorder's PCM16 WAV and every common encoder's output measure as before.
- **Frames, not file length over bitrate.** For variable bitrate files the first frame's bitrate over the file length can be off by half in either direction (a 4-minute clip could read as 6), so it is no longer used; counting frames is exact and costs one pass over at most `MAX_UPLOAD_MB`.
- **A per-request audio total is not added.** The spec's rule is per clip, and upload size and the storage quota already bound what one message can carry. The open item from P4.1 (audio has no token estimate, so the window check ignores it) stays open for P6.1.
- **The smoke test asks for usage where Copilot does.** The `openai` preset with a base URL override exercises the dialect that sends `stream_options`; the `custom` connection checks the other side (a reply without usage still completes), so a change in when Copilot asks shows up either way.
- **Fork pull requests build but upload nothing.** The guard keeps the build and its checks (they still prove the change compiles) and only drops the uploads; same-repository pull requests and pushes upload as before.
- **Backup off entirely, not just for the WebView folder.** The app keeps nothing worth restoring (the server address and the token are re-entered in a minute), and excluding every domain needs no knowledge of where the WebView keeps its files.
- **Focus on touch screens goes to the microphone.** Moving focus to the text area after Stop opens the on-screen keyboard over the new clip on a phone, so touch screens get the microphone button, which TalkBack still announces.
