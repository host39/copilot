## Decisions

- **One release version.** The server image, the native apps, and the web app they bundle ship together, so one version covers them, kept in `workspace.package.version` and `apps/native/package.json` (Tauri reads the version from there). The web and contracts packages stay private `0.0.0`: they are never published on their own.

## Owner Checkpoints

These need the owner's keys, devices, or GitHub settings; agents do not tick them.

- **P3.4 live checks:** a Gemini 3 or 4 tool loop over two turns and a WAV clip to Gemini. A `400` about a missing `thought_signature` means building a native adapter against the Interactions API with `store: false` (large; only then).
- **P5.4 device test:** the "Device Test Checklist (P5.4)" in `apps/native/README.md`, on a Linux desktop and an Android phone, plus the mobile web through the HTTPS proxy.
- **Android release signing:** choose the `applicationId` (`apps/native/README.md`, "Changing the Identifier"), create the keystore, and add `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, and `ANDROID_KEY_PASSWORD` to the repository secrets. Tag builds fail without them.
- **Branches and tags:** create `main`, make it the default branch, and push the `v0.1.0` tag (cloud sessions cannot push tags).
- **Image visibility:** after the first tag run, make the `ghcr.io/host39/copilot` package public in its package settings, if GitHub created it private.
- **lib-rustauth tag:** push lib-rustauth's `v0.1.0` tag to GitHub; then the pin in the root `Cargo.toml` can switch from `rev` to `tag = "v0.1.0"`.
